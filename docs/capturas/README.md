# Capturas

Esta carpeta contiene las capturas de pantalla usadas por el README.

## Cómo añadir una captura

1. Guarda la imagen aquí con un nombre descriptivo, por ejemplo
   `interfaz-general.png` o `botones.png`.
2. Enlázala en el `README.md` con Markdown:

   ```markdown
   ![Interfaz general](docs/capturas/interfaz-general.png)
   ```

3. Usa PNG para mejor calidad. Evita archivos gigantes (redimensiona a 1920 px de ancho como máximo).

## Sugerencias de capturas

- Interfaz completa en juego.
- Modo edición con anclajes visibles.
- Menú de configuración (`/capri`).
- Botones de acción y joystick.
- Bolsas y banco personalizados.
- Ventana de mazmorras (Ventanas Grandes).
- Comparativa antes/después del escalado.
